# ACIO Calculator

ACIO Calculator is a lightweight, browser-based calculator app designed to handle everyday and practical calculations in one place. It brings together common math tools into a simple interface so users can perform calculations without needing multiple apps or websites.

The name "ACIO" stands for "All Calculations in One," which reflects the purpose of this project: a single toolkit for quick problem solving.

## What this project is used for

This application is useful for:

- Basic arithmetic and quick everyday calculations
- Scientific calculations such as trigonometric and logarithmic functions
- Percentage-based calculations for discounts, changes, and comparisons
- Unit conversion for length, weight, temperature, area, and digital storage
- Date and time calculations for finding differences or adding/subtracting days
- Loan and interest estimation for repayment planning
- BMI calculation for health and fitness tracking

## Main features

- Standard calculator with arithmetic operations
- Scientific calculator with functions like sin, cos, tan, log, ln, square root, powers, and pi
- Percentage calculator for percentage value and percentage change
- Unit converter for common conversions
- Date calculator for day differences and date adjustments
- Loan calculator for monthly payments and interest estimate
- BMI calculator with standard adult range guidance
- Quick-access tools and recent calculation history
- Responsive design for desktop and mobile devices

## Why it is useful

This project is helpful for:

- Students who need quick revision calculations
- Office users doing daily financial or productivity calculations
- Shoppers comparing discounts and price changes
- Travelers converting units between systems
- Anyone checking dates, repayments, or health metrics

Because it runs in the browser, it is fast, simple, and easy to use without installation or setup.

## Project structure

The project is intentionally simple and contains a single main file:

- `index.html` - complete app interface, styling, JavaScript logic, and calculator functionality

## How to run it

### Option 1: Open directly in the browser

1. Go to the project folder
2. Double-click `index.html`
3. The calculator will load in your browser

### Option 2: Run a local server

From the project directory, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Technologies used

- HTML5
- CSS3
- JavaScript
- No backend is required

## Notes

- All calculations are performed in the browser
- The app does not store data on a server
- It is a static web app, so it is lightweight and easy to share

## Summary

ACIO Calculator is a practical all-in-one calculator web app for everyday problem solving. It is useful for arithmetic, scientific math, conversions, finance, date calculations, and health metrics, making it a convenient tool for students, professionals, and general users.
